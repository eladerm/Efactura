# ELAPIEL eFactura - Copia de Seguridad

Este proyecto es una aplicación de Facturación Electrónica para **ELAPIEL**, optimizada para el ambiente de pruebas del SRI.

## Cómo descargar tu código

Para generar una copia de seguridad de todos tus archivos:

1. Ejecuta el siguiente comando en la terminal:
   ```bash
   npm run export
   ```
2. Una vez finalizado, verás el archivo `elapiel-project.tar.gz` en el explorador de archivos.
3. Haz clic derecho sobre él y selecciona **Download (Descargar)**.

## Tecnologías
- Next.js 15 (App Router)
- Tailwind CSS (Diseño ELAPIEL Luxury)
- Firebase (Auth, Firestore, Storage)
- Open-Factura (Integración SRI)
